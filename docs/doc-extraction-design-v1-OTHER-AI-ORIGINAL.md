# 第三篇：文档抽取，"一次抽取" vs "便宜模型先做、没把握再交给贵模型"（实验设计 v1）

2026-11-02 · 只用公开数据 · 预算上限 $500（核心估计 $150–300）

## 1. 一句话卖点

便宜模型先抽取，**每个字段给一个校准过的信心**，没把握的文档再交给贵模型（或人工）。我们在公开数据集上、按相同花费比较，证明这种"事后看信心再升级"的做法比"一律用贵模型"省很多钱、准确率几乎不掉，也比"事前看文档特征决定用哪个模型"更好。

## 2. 必须正面回应的最接近工作（新查到）

**Pre-Inference Routing for Cost-Efficient Document Field Extraction**（Rajendran, 2026, [arXiv 2608.06607](https://arxiv.org/pdf/2608.06607)）
- 做法：**调用模型之前**，用 13 个文档特征（OCR 质量、版面等）预测这份文档难不难，再决定用 Haiku 还是 Opus。
- 数据：CORD、SROIE、DeepForm、DocILE、POIE、VRDU（和我们想用的几乎一样）。
- 结果：收据省 31–33% 的钱，F1 只差 0.02 以内；发票等类型路由不起作用。
- 它也比了"先便宜后升级"，结论是不如事前路由。**但它的升级判断用的是事前路由器自己的信号，不是模型输出后的信心**。作者说 Anthropic 不给 logprob，所以没做基于信心的升级。另外它只用了一家（Anthropic）的模型。

**我们的区别（论文主线）**：
1. 升级看**模型输出后的字段级信心**（自报信心、logprob、多次采样一致性、两个便宜模型是否一致、值能不能在 OCR 文本里找到），并用 Platt / isotonic 校准。
2. **多家模型**：OpenAI、Google、Anthropic，加上开源模型。也测跨家组合，比如 Gemini Flash 升级到 GPT-5。
3. 直接和事前路由做**相同花费下的对比**。如果我们赢了，就推翻它"cascade 不如事前路由"的结论，这本身就是很好的卖点；如果输了，也是有价值的复现结果。
4. 第三层是人工：字段级交给人复核，算总成本（API 费用 + 人工费用）。

其他相关工作见 [doc-extraction-related-work.md](doc-extraction-related-work.md)，主要是 2603.22651 多 agent 架构成本、2609.20110 / 2606.24420 字段信心。通用的 LLM cascade 工作有 FrugalGPT（2023）和 BARGAIN（[arXiv 2509.02896](https://arxiv.org/html/2509.02896v1)），但都不是做文档抽取的。

## 3. 研究问题

- **RQ1**：便宜模型比贵模型差多少？差在哪些字段、哪类错？
- **RQ2**：哪种信心信号最能发现便宜模型的错？校准后准不准（ECE）？换数据集还准不准？
- **RQ3**：相同花费下比较"一律便宜 / 一律贵 / 事前路由 / 事后信心升级 / 自检 / 两个便宜模型互查"，哪个的成本–准确率曲线最好？
- **RQ4**：加上人工这一层后，在不同人工单价下，最省的组合是什么？

## 6. 核心省钱技巧：每个模型对每份文档只跑一次，所有 cascade 都离线模拟

- 把所有模型对所有文档的输出和花费都存下来。
- 各种升级阈值、各种组合（便宜 A → 贵 B）都用存下来的结果离线计算，**不会再花 API 的钱**。
- 这样 4 个便宜 × 3 个贵 = 12 种组合 × 任意阈值，都能免费得到。

## 7. 信心信号（便宜模型）

| 信号 | 额外花费 |
|---|---|
| 自报信心（每个字段 0–100） | 0 |
| logprob（OpenAI、开源模型可以拿到） | 0 |
| OCR 匹配：抽到的值能不能在 Tesseract OCR 文本里找到 | 0（本地跑） |
| 多次采样一致性（同一模型再跑 2 次） | +2 次便宜调用 |
| 两个便宜模型是否一致 | 用已有输出，不额外花钱 |
| 自检：把结果给模型看，问"有没有错" | +1 次便宜调用 |

校准：Platt、isotonic，在训练集上拟合，测试集上评估；再做"在 CORD 上拟合、用到 SROIE 上"的跨数据集测试。

## 8. 对比方法

1. 一律便宜模型
2. 一律贵模型（准确率上限参考）
3. 事前路由（复现 2608.06607 的简化版：文档特征 + 随机森林）
4. **事后信心升级（我们的）**：文档内最低字段信心低于阈值就整份交给贵模型，再按字段合并两边结果
5. 自检（便宜模型自己检查一遍）
6. 两个便宜模型互查，不一致的升级
7. Oracle：知道哪份错了才升级（理论上限）

## 9. 指标

- 字段级 F1（规范化后完全匹配），文档级全对率
- 每 1000 份文档的美元花费、平均延迟
- 成本–准确率曲线和 Pareto 前沿；"达到贵模型 99% 的 F1 需要花多少钱"
- 信心：AUROC、ECE、风险–覆盖率曲线（AURC）
- 总成本 = API 费用 + 交给人工的字段数 × 人工单价（扫描不同单价）
- 出错类型：看错字、找错字段、格式不对、凭空编造、漏抽
- 统计：按文档 bootstrap 置信区间
